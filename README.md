# Data-OCR

Mock Card Studio — เว็บแก้ข้อมูลบัตรจำลองสำหรับ NTB / DEV และส่งออก PNG

## ใช้งาน
- แก้ข้อความในแท็บบุคคล / วันและที่อยู่
- วันที่กรอกเป็น ค.ศ. และแสดง พ.ศ. บนบัตรโดยอัตโนมัติ
- ใช้รูป Luffy ตามต้นแบบ หรือเลือกรูป PNG/JPG/WebP และปรับขนาด/ตำแหน่ง
- ดาวน์โหลด PNG ขนาด 1536×1024 หรือ 3072×2048
- ข้อมูลผิดรูปแบบเตือน แต่ไม่บล็อก negative test
- ข้อมูลและรูปที่กรอกประมวลผลในเบราว์เซอร์ ไม่มี API บันทึกข้อมูล ไม่มี autosave

## ขอบเขตความเหมือนต้นแบบ
ใช้ภาพ mock ที่เจ้าของให้เป็นฐาน เมื่อยังไม่แก้ข้อมูลจะคงพิกเซลต้นฉบับ
เมื่อแก้หรือล้างข้อความ ระบบใช้ clean plate แบบเต็มใบแล้ววาดทุกช่องใหม่ด้วย Sarabun
เพื่อไม่ให้เหลือเงาตัวอักษรเดิมหรือรอยต่อสี่เหลี่ยมระหว่างช่อง
จึงไม่รับประกันฟอนต์/พื้นหลังบริเวณแก้ไขเหมือนต้นฉบับ 100%
ทุกภาพคงข้อความ MOCK DATA • DEV TEST • NOT VALID ไว้
บาร์โค้ด ชิป ตรา และลายเซ็นเป็นภาพคงที่ ไม่ได้เข้ารหัสข้อมูลใหม่
ไม่ใช่บัตรจริง ไม่ใช้ยืนยันตัวตน และไม่รับรองผล OCR/KYC ของระบบปลายทาง
ที่อยู่รองรับพื้นที่ 2 บรรทัด; ค่าที่ยาวมากจะเตือนการตัด
รหัสหน่วยงานไม่มีในต้นแบบ จะเพิ่มใต้ตราเมื่อกรอกเท่านั้น

## พัฒนา
Node.js >=22.13; โครงการใช้ React + TypeScript + Vinext/Vite และ Canvas
ติดตั้ง dependency ตาม lockfile ด้วย `npm ci`
เริ่มพัฒนาด้วย `npm run dev`
ตรวจชนิดด้วย `npx tsc --noEmit`
ตรวจ build และ tests ด้วย `npm test`

สคริปต์ build ของ scaffold ใช้ Linux/WSL ที่มี bash, flock, curl, GNU timeout
macOS สามารถพัฒนาผ่าน Vite ได้ แต่ build helper ต้องใช้สภาพแวดล้อม Linux/WSL
ไม่ต้องใส่ API key สำหรับการแก้ข้อมูลหรือสร้าง PNG

## ส่วนสำคัญ
- `app/studio.tsx`: ฟอร์มและการส่งออก
- `lib/card-data.ts`: ข้อมูลเริ่มต้นและตรวจรูปแบบ
- `lib/draw-card.ts`: วาดภาพและกำหนดบริเวณแก้ไข
- `public/card-reference.jpeg`: ภาพ mock ต้นฉบับที่เจ้าของให้
- `public/card-clean.png`: พื้นหลังสำหรับแทนข้อความที่แก้ไข (สร้างด้วย built-in imagegen)
- `public/fonts/OFL.txt`: ใบอนุญาต Sarabun
- `REVIEW.md`: ผลตรวจและข้อจำกัด

ไม่มีการเปลี่ยนข้อมูลในระบบธนาคาร ไม่มี OCR API และไม่มีการเชื่อมต่อ NTB จากเว็บนี้
